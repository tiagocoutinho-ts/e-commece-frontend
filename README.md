## Ecommerce Frontend

Este é o projeto de **Frontend** (interface visual) para uma plataforma de e-commerce. Ele foi desenvolvido para oferecer uma experiência de compra simples, rápida e bonita para os usuários.

## Integração com o Backend
**Cliente de:** [e-commerce-api](https://github.com/tiagocoutinho-ts/e-commerce-api) 
O frontend consome os dados de produtos, carrinho e usuários diretamente desta API.
